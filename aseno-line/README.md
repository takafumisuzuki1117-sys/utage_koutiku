# アセノ 公式LINE連携（見込み客用 @225hvwib）

友だち追加の直後に、LINEのトーク画面の中で3つの質問をボタンで聞きます。答えは「会員連絡（回答・名簿）」スプレッドシートの **LINE友だち** シートに、1人1行で記録されます。体験申込フォームとも自動でつながります。

- Googleフォームのアンケートは使いません。ボタンを押すだけで、LINEの外に出ないので離脱しにくくなります。
- フォームは今の「無料体験申込」の1つだけです。LINEから開くと、学年とLINE受付番号が入った状態で開きます。
- 費用はかかりません。自動の返信は無料です。無料枠（月200通）を使うのは、体験申込のお礼（1人1通）と、`askAllFriends()` で一斉送信したときだけです。

## 友だちから見た流れ

1. 友だち追加すると、あいさつと「① お子さまの学年は？」が届く
2. ボタンで答える → ②「アセノを知ったきっかけ」→ ③「いまのお気持ち」
3. 答えに合わせた返信が届く
   - 体験してみたい → 体験申込ボタン（学年とLINE受付番号は入力済み）
   - 送迎が気になる → 送迎の説明と体験申込ボタン
   - イベントなら行きたい／まずは情報がほしい → 「日程が決まったらお知らせします」と体験申込ボタン
4. 体験申込を送信すると、LINEにお礼が届く。今までどおり、メールの自動返信と担当者への通知も届く

## LINE友だち シートの列

| 列 | 中身 |
|---|---|
| 友だち追加日時 | 友だち追加した日時 |
| LINE表示名 | LINEの名前 |
| 学年／きっかけ／いまのお気持ち | 3つの質問の答え |
| 回答日時 | 3問目まで答えた日時 |
| 体験申込日時／体験申込のお名前 | LINEから体験申込をした日時と、お子さまの名前・学年 |
| 状態 | 友だち／友だち（再追加）／体験申込済／ブロック |
| メモ | 自由に書いてOK（プログラムは触りません） |
| LINE受付番号 | その人のLINEの番号。消さないでください |

列の並べ替えや追加をしても動きます。見出しの名前だけは変えないでください。

## 設定手順（30〜45分）

**Google側の作業は、必ずクラブのGoogleアカウント（asenofc@trust.ocn.ne.jp）でログインして行ってください。** 体験申込フォームとスプレッドシートの持ち主がこのアカウントだからです。

### A. LINE側：Messaging API を使えるようにする

1. LINE公式アカウント管理画面（@225hvwib）を開き、右上の **設定** → 左メニューの **Messaging API** → **Messaging APIを利用する**
2. 初めてのときは開発者情報（名前・メールアドレス）を登録します
3. プロバイダーは **新規作成**、名前は「アセノサッカークラブ」。プライバシーポリシーと利用規約は空欄で構いません → **OK**
4. [LINE Developers](https://developers.line.biz/console/) に同じLINEアカウントでログインし、プロバイダー「アセノサッカークラブ」→ チャネル「アセノサッカークラブ」→ **Messaging API設定** タブを開きます
5. 一番下の **チャネルアクセストークン（長期）** で **発行** を押し、出てきた長い文字列をコピーします
6. 同じタブの「Webhookの再送」は **オフのまま** にしてください

> Messaging API は、一度有効にすると元に戻せません。今のあいさつメッセージ、リッチメニュー、応答メッセージ、チャットはそのまま使えます。

### B. Google側：プログラムを置く

1. https://script.google.com を開き、**新しいプロジェクト** を作ります。名前は「アセノLINE連携」にします
2. 最初から入っている `コード.gs` の中身を全部消し、このフォルダの `Code.gs` を丸ごと貼り付けて保存します
3. 左の歯車 **プロジェクトの設定** → 一番下の **スクリプト プロパティを追加**
   - プロパティ：`LINE_TOKEN`
   - 値：A-5 でコピーしたトークン
   - → **スクリプト プロパティを保存**
4. エディタに戻り、上の関数の選択欄で `setup` を選んで **実行** します
   - 権限の確認が出たら **権限を確認** → アカウントを選ぶ → **詳細** → **（安全ではないページ）に移動** → **許可** の順に進みます
   - 実行ログに「セットアップ完了」と **Webhookの合言葉** が出ます。合言葉はメモしておいてください
   - このとき体験申込フォームの最後に「LINE受付番号」欄が自動で追加され、スプレッドシートには「LINE友だち」シートができます
5. 右上の **デプロイ** → **新しいデプロイ** → 種類の歯車から **ウェブアプリ** を選びます
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - → **デプロイ**。表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーします
6. そのURLをブラウザで開き、「アセノLINE連携は動いています。」と出れば成功です

### C. LINE側：つなぐ

1. LINE公式アカウント管理画面の **設定** → **Messaging API** → **Webhook URL** に、次をつなげて入力し、保存します

   ```
   （B-5のウェブアプリのURL）?key=（B-4の合言葉）
   ```

   例：`https://script.google.com/macros/s/AKfy…/exec?key=1a2b3c4d5e6f7a8b`

   「検証」ボタンでエラーが出ることがありますが、Googleのしくみ上そうなることがあるだけです。D のテストで動けば問題ありません。
2. **設定** → **応答設定** で、次のように設定します
   - **Webhook：オン**
   - **あいさつメッセージ：オフ**（あいさつはプログラムが質問と一緒に送ります。2通重ならないようにするためです）
   - チャットと応答メッセージは今のままにします

### D. テスト（自分のスマホで）

1. アセノのLINEをいったん **ブロック** し、すぐに **ブロック解除** します（友だち追加と同じ扱いになります）
2. あいさつと「① お子さまの学年は？」のボタンが届くことを確かめます
3. 3問答えて、LINE友だち シートに1行入ることを確かめます
4. ボタンを押したときに、応答メッセージの「担当者が確認して…」が **出ない** ことを確かめます。出た場合は鈴木に知らせてください
5. ③で「体験してみたい」を選び、届いたボタンからフォームを開きます。学年とLINE受付番号が入っていることを確かめます
6. テスト内容で送信し、LINEにお礼が届き、シートの「体験申込日時」が埋まることを確かめます
7. テストの行（LINE友だち シートと体験申込シート）を削除します。質問をもう一度試したいときも、自分の行を消してからブロック→解除します

### E. リッチメニューをプログラムで置く（5分）

管理画面のリッチメニュー①はフォームのURLを直接開くので、そこから申し込んだ人はLINEの友だちと結びつきません。プログラムでメニューを置き直すと、①を押した人にその人専用の申込ボタンが返るようになります。管理画面での設定変更は要りません。

メニューの画像は `richmenu.png`（2500×1686、3列×2段）です。元のデザインは `richmenu-src/richmenu.html` にあります。

| 位置 | ボタン | 押したとき |
|---|---|---|
| 上段左 | 無料体験申込 | プログラムが、学年とLINE受付番号入りの申込ボタンを返す |
| 上段中 | 送迎について | 「送迎について」と送信 → 管理画面の応答メッセージが返信 |
| 上段右 | 今月の予定 | 「今月の予定」と送信 → 管理画面の応答メッセージが返信 |
| 下段左 | お問い合わせ | 「お問い合わせ」と送信 → 管理画面の応答メッセージが返信 |
| 下段中 | Instagram | https://www.instagram.com/aseno_sc/ を開く |
| 下段右 | ホームページ | http://www.aseno.co.jp/ を開く |

1. `Code.gs` を最新版に貼り替えて保存します（⌘A → Delete → 貼り付け → ⌘S）
2. **デプロイ** → **デプロイを管理** → 鉛筆マーク → バージョンを **新バージョン** にして **デプロイ** します。URLは変わりません
   - これをしないと、LINEからの受け口が古いプログラムのままなので、①を押しても何も返りません
3. 上の関数の選択欄で `installRichMenu` を選んで **実行** します。実行ログに「リッチメニューを置きました」と出れば完了です
4. スマホでトーク画面を開き直し、6つのボタンを1回ずつ押して確かめます
   - ②〜④で「担当者が確認して…」が出たら、管理画面の応答メッセージのキーワードが違っています。キーワードをボタンの文字（送迎について／今月の予定／お問い合わせ）と同じにしてください

**注意**：プログラムで置いたメニューは、管理画面で作ったメニューより優先して表示されます。管理画面でリッチメニューを編集しても表示は変わりません。

- メニューのボタンやリンク先を変えたいとき：`Code.gs` の `RICHMENU` を書き換えて保存し、`installRichMenu` をもう一度実行します
- 管理画面で作ったメニューに戻したいとき：`removeRichMenu` を実行します

## 運用

- **Webhookを入れる前に友だちになった人**：`askAllFriends` を1回実行すると、全員に質問①が届きます。友だちの人数ぶん無料枠を使います
- **質問や返信の文章を変えたいとき**：`Code.gs` の上のほうにある `CONFIG`（あいさつ・送迎の説明など）と `QUESTIONS`（質問とボタン）を書き換えて保存し、**デプロイ** → **デプロイを管理** → 鉛筆マーク → バージョンを **新バージョン** にして **デプロイ** します。URLは変わりません
- **ボタンは13個まで、ボタンの文字は20文字まで** です
- **HP・チラシのURLから直接フォームを開いた申込** は、LINE受付番号が空になるので、今までどおりメール通知だけになります
- **プログラムを書き換えたとき** は、保存したあと必ず **新バージョン** でデプロイし直してください。LINEからの受け口は、デプロイしたときのプログラムで動きます（`setup`・`installRichMenu` など、エディタから実行する関数は保存しただけで最新になります）
